# After Effects Skills

Три навыка Codex для локальной работы в Adobe After Effects: проект и экспорт, динамичный монтаж отснятого видео, анимированные титры.

| Навык | Назначение | Включённый JSX |
|---|---|---|
| `after-effects-workflow` | Инспекция проекта, поддерживаемые MCP-операции, рендер и обмен с Premiere | Локальный JSON-отчёт о композициях и слоях |
| `after-effects-dynamic-editing` | Ритм, покадровый монтажный план, новая композиция и изменение скорости | Сборка композиции из локальных кадров по конфигурации |
| `after-effects-titles` | Редактируемые титры и карточки с анимацией под размер кадра | Новая композиция с текстом и нативной графикой |

## Установка

Через Vercel Skills CLI:

```powershell
npx skills add leo-skazka/after-effects-skills --skill after-effects-workflow --skill after-effects-dynamic-editing --skill after-effects-titles -g -y
```

Либо через встроенный `$skill-installer`, указав этот репозиторий и папки `skills/after-effects-workflow`, `skills/after-effects-dynamic-editing`, `skills/after-effects-titles`.

## Примеры заданий

- «Используй after-effects-workflow: проверь композиции проекта и подготовь экспорт отдельной версией».
- «Используй after-effects-dynamic-editing: собери 20-секундный ролик из локальных файлов под музыкальные акценты, 9:16, 30 fps».
- «Используй after-effects-titles: сделай редактируемые титры с этим текстом, шрифтом и цветами».

Указывайте локальные пути к материалам, результат, размер кадра, длительность, FPS и референс, если он есть. Тексты и параметры бренда берутся из задания; логотипы, цвета и фирменные шрифты не предполагаются заранее.

## Выполнение в After Effects

В каждой папке навыка есть `SKILL.md`; ресурсы запускаются по его инструкции. Для JSX сначала заполните конфигурацию копии шаблона, затем в AE выберите `File > Scripts > Run Script File`. Сборочные шаблоны создают отдельные композиции и не начинают сохранение или рендер автоматически.

Произвольное выполнение JSX через Premiere MCP не предполагается. Если подключённый мост предоставляет только инспекцию, Dynamic Link и управление очередью, используйте именно эти зарегистрированные операции. Подготовка JSX, исполнение в AE и проверенный рендер — разные результаты.

Для записи JSON-отчёта может потребоваться настройка AE `Allow Scripts To Write Files And Access Network`; навыки не включают её автоматически. Рабочие видео, AEP, отчёты с путями медиа и результаты рендера остаются локально.

## Проверки и пределы проверки

Структура навыков проверяется штатным `quick_validate.py`; JSX проверяется на синтаксис и в изолированных mock-сценариях. Mock-проверки не доказывают корректность шрифтов, реального декодирования, Time Remap или картинки в конкретной версии Adobe. Перед использованием шаблона в рабочем проекте нужен контрольный запуск в AE и просмотр результата.

Навыки не содержат Adobe, плагины, шрифты или медиаматериалы. Ссылки на документацию и особенности конкретных операций находятся в соответствующем навыке.
