# Геометрия и выполнение титров

## Что сохранять при адаптации шаблона

- `sourceRectAtTime(t, false)` возвращает прямоугольник в координатах слоя: `left`, `top`, `width`, `height`. Anchor Point `[left, top]` делает Position верхним левым углом видимых границ. У point text исходный anchor часто находится у базовой линии, поэтому просто `[0, 0]` даёт неверный отступ.
- Текст, кегль и шрифт нужно задать до измерения. Метод не проверяет наличие нужных глифов; такой контроль требует просмотра в AE. Измерение текста не учитывает все последующие эффекты; тени, обводки и blur требуют дополнительного запаса.
- `build-titles.jsx` использует point text и явные переносы `\n`/`\r`. Его подгонка уменьшает кегль до указанного минимума и затем останавливается с ошибкой. Для сложной верстки замени её осмысленными переносами или отдельными текстовыми блоками.
- Размеры и положение карточки рассчитываются заново для каждого формата. Position всех слоёв проходит одинаковое смещение внутри заданной безопасной области. При нехватке места движение сокращается вплоть до fade-only.
- Создание свойства через `addProperty()` в indexed group может инвалидировать старые ссылки на соседние свойства. Закончи настройку добавленного rectangle до добавления fill, либо получай свойства повторно по сохранённому индексу.
- Времена внутри шаблона задаются целыми кадрами. После изменения FPS проверь длительность чтения; совпадение числа кадров не означает совпадение секунд.

## Граница автоматизации

JSX выполняется ExtendScript внутри After Effects, а не Node.js. Проверка парсером Node после удаления `#target` обнаруживает синтаксические ошибки, но не доказывает работу AE API, шрифтов или рендера. Mock-проверка геометрии также не заменяет визуальный контроль.

Доступные в среде AE-инструменты могут ограничиваться проверкой моста, передачей композиции и очередью рендера. Используй только обнаруженные схемы инструментов. Без инструмента выполнения JSX готовый файл запускается пользователем через File → Scripts → Run Script File. Шаблон не требует доступа к сети или записи внешних файлов.
