# After Effects: проект, скрипты и экспорт

Работай в выбранном пользователем After Effects. По умолчанию материалы обрабатываются локально; параметры бренда, кадровая частота и пути берутся из задания и проекта.

## Определи реальный способ управления

- Если доступны инструменты `premiere-pro`, начни с `get_capabilities` с коротким запросом `After Effects` и `tool_limit: 10`. Прочитай точную схему нужного инструмента; само наличие Premiere MCP не означает управление слоями AE.
- Перед обращением к AE вызови `verify_after_effects_connection`. Для операций между приложениями отдельно проверь Premiere через `verify_premiere_connection`. Ошибку соединения, прав или ACL передай точно; она не доказывает, что программа не установлена.
- В проверенной конфигурации есть узкие операции инспекции, Dynamic Link, подготовки очереди и импорта рендера. Универсальный исполнитель JSX не подтверждён. Повторно обнаруживай возможности при изменении среды; не отправляй AE-код исполнителю Premiere и не включай `unsafe-script` для обхода отсутствующего инструмента.
- При отсутствии подходящего исполнителя подготовь самостоятельный `.jsx` и укажи запуск `File > Scripts > Run Script File`. Не выдавай написанный скрипт за выполненную правку. Командный запуск `AfterFX.exe -r` допустим как самостоятельный, явно выбранный путь только в рамках действующих разрешений среды.

## Прочитай проект перед изменениями

Установи нужные project/comp/layer ID и исходные размеры, FPS, длительность, рабочую область, источники, missing footage, текст и шрифты. Имена могут повторяться; перед изменением сверяй ID и контекст. Старые версии AE могут не предоставлять `Layer.id`, поэтому используй также ID композиции, индекс и имя слоя.

Если нужен локальный отчёт и подходящего инструмента нет, используй [assets/inspect-project.jsx](assets/inspect-project.jsx). Он читает проект и пишет JSON в выбранный файл, не сохраняет AEP и не меняет таймлайн. В `CONFIG` можно ограничить композицию и объём отчёта. Пути медиа по умолчанию исключены; включай их только если нужны для задачи. Не публикуй полученные отчёты или пользовательские медиа вместе с навыком.

## Подготовь и проверь изменение

- Для черновика создай отдельную именованную композицию и папку; не меняй исходные композиции ради демонстрации.
- Для точечной правки изменяй разрешённую композицию и указанные свойства. Учитывай существующие expressions, ключи, parenting, track mattes, precomp, color management и интерпретацию FPS.
- В JSX используй match names свойств для независимости от языка интерфейса. Оборачивай изменения в `beginUndoGroup` / `endUndoGroup` с `try/finally`. Проверяй файлы, диапазоны и коллизии имён до изменения проекта.
- Сохраняй в новый `.aep` либо в явно указанный пользователем файл. Для записи отчёта AE может требовать разрешение scripts write files; не включай его без необходимости или поручения. Изменение композиции в памяти само по себе не требует сетевого доступа.
- После исполнения прочитай фактическое состояние. Проверяй начало, середину и конец движения, края слоёв, шрифты и offline media. Статическая проверка JSX не заменяет просмотр в AE.

Для динамичной сборки используй `after-effects-dynamic-editing`, если он установлен; для титров — `after-effects-titles`. При отсутствии этих навыков продолжай по задаче с документацией AE, не объявляя их обязательными зависимостями.

## Рендер и связь с Premiere

Перед экспортом прочитай [references/render-and-handoff.md](references/render-and-handoff.md). Там различены подготовка очереди и завершённый рендер, шаблоны AE, альфа и фактическое выполнение `aerender`.

При Dynamic Link сначала получи preview операции и разреши конкретные потери/ограничения переноса. Токены preview принадлежат конкретным проектам, клипам и версиям состояния; они одноразовые. Выполняй apply только при уже имеющемся разрешении на конкретную операцию и её побочные действия. Если разрешения недостаточно, сначала подготовь конкретный preview для решения пользователя. Не выводи факт разрешения из наличия токена.

## Что сообщить в результате

Назови созданную композицию/изменение и проверенный файл. Различай четыре состояния: **скрипт подготовлен**, **выполнен в AE**, **проверен просмотром**, **отрендерен**. Укажи только достигнутые состояния. Для готового видео проверь длительность, размеры, FPS, звук и альфа-канал, если он заказан.
